creel.export.to_lacing¶

creel → lacing: carry a creel annotation into lacing’s envelope, source link intact.

A creel.annotate.Annotation knows where a fact came from: its target can be a Selection (a source region plus a grounding selector) and its provenance says whether a model or a person made it. lacing’s lacing.Annotation is what decks, videos and reports render, but lacing has no source selector of its own (its Reference is media, node or annotation). This adapter is the bridge thorwhalen/loomun#35 and its ADR-0012 call for: one function that maps the envelope and the provenance, and keeps the whole creel record in the body, so a rendered fact can always drill back to its source.

>>> from creel.annotate import Annotation, Selection
>>> from creel.evidence import Provenance, TextQuoteSelector, SOFTWARE_AGENT
>>> sel = Selection("s1", "report.pdf", TextQuoteSelector(exact="revenue grew 12%"))
>>> note = Annotation(
...     "a1", sel, "fact:revenue-growth", motivation="identifying",
...     provenance=Provenance("report.pdf", "llm:extract", attributed_to="model-x",
...                           attributed_kind=SOFTWARE_AGENT),
... )
>>> ann = to_lacing_annotation(note)
>>> source_selection(ann)["source"]
'report.pdf'

Needs lacing: pip install creel[lacing]. Nothing here is imported until called.

creel.export.to_lacing.node_path(target)[source]¶

The NodeRef.scene_path that stands for a creel target.

A source selection points at its source, a graph element at the element, and an (element_id, attribute) pair at that attribute of the element. The precise region (the selector) is in the body: see source_selection().

A / or % inside an id is percent-escaped, so ("a", "b") and "a/b" never share a path.

>>> node_path("n1"), node_path(("n1", "name")), node_path("a/b")
('creel/element/n1', 'creel/element/n1/name', 'creel/element/a%2Fb')
Return type:

str

creel.export.to_lacing.to_lacing_annotation(annotation, *, tier='creel', reference=None, attributed_to=None, generated_by=None, namespace=UUID('9d6c3f0e-5b6a-5c1e-9a4e-6372656c0001'))[source]¶

A lacing.Annotation carrying annotation, source link intact.

Parameters:

  • annotation (Annotation) – The creel annotation.

  • tier (str) – The lacing tier it goes in.

  • reference (Union[Any, Callable[[Annotation], Any], None]) – What it annotates in lacing: a lacing Reference, or a function of the creel annotation that returns one. Default: a NodeRef at node_path(), a point at time 0 (a document region has no time).

  • attributed_to (Optional[str]) – Who is responsible, when the creel provenance does not say. Required in that case: lacing records a responsible party on everything.

  • generated_by (Optional[str]) – lacing’s was_generated_by. Default: adapter:creel@<creel version>, as lacing’s own loaders stamp what they import; the creel extractor id stays in the body’s provenance.

  • namespace (UUID) – The uuid5 namespace of the lacing ids. creel ids are chosen per corpus, and lacing ids are unique across a whole store, so give each corpus its own namespace (uuid.uuid5(CREEL_ID_NAMESPACE, corpus)) when several share one lacing store.

The lacing id is lacing_id() of the creel id in namespace, so re-exporting is idempotent. was_derived_from holds the lacing id of the record a creel revision supersedes (was_revision_of). The body is the full creel record.
